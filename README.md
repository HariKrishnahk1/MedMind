# AI/ML Deterioration Prediction Engine

> [!IMPORTANT]
> **Safety & Research Disclaimer**: This repository contains a **clinical decision-support research prototype** built on synthetic/de-identified data. It does **not** provide medical diagnoses, treatment recommendations, prescriptions, or clinical validation. Predictions generated by this system must not be used independently for clinical decision-making.

---

## Project Overview

The **AI/ML Deterioration Prediction Engine** is a reproducible machine-learning pipeline and prediction microservice designed to analyze longitudinal patient clinical observations (vital signs, laboratory measurements, demographics, and active medications) and predict the probability of **near-term clinical deterioration**.

The system integrates continuous patient-specific baseline tracking, clinical trajectory feature engineering, leak-free temporal modeling, and **SHAP (SHapley Additive exPlanations)** feature attribution to explain model predictions.

```

       │
       ▼

       ▼

       │

       │
       ▼

       │
       ▼
Model Evaluation & Metrics Export (src/models/evaluate.py)
       │
       ▼
SHAP Feature Contribution Explainer (src/explainability/shap_explainer.py)
       │
       ▼
FastAPI REST Service Endpoints (src/service/app.py)
```

---

## Key Technical Features

1. **Synthetic Longitudinal Dataset**: Generates 750 heterogeneous synthetic patient profiles with 20–45 observations per patient across several simulated monitoring days, including missing values, irregular observation gaps, and acute deterioration trajectories.
2. **Personal Baseline & Trend Engineering**: Computes patient-specific baselines, rolling statistics (mean, std, min, max), rate of change per hour, trend slopes, and deviation from personal baseline using strictly past observations ($t \le T$).
3. **Zero Data Leakage**: Implements group-based patient-level train/test splitting (80% train / 20% test). Preprocessors are fit exclusively on training data, and target construction ($t > T$) is completely isolated from model input features.
4. **SHAP Explainability**: Returns patient-specific top feature risk contributors (+ increased risk / - decreased risk) for every inference request.
5. **Configurable Microservice**: Exposes a FastAPI REST endpoint (`POST /predict`) with configurable risk thresholds and prediction horizons via `config/model_config.yaml`.

## Installation & Setup

### Prerequisites
- Python 3.9+ installed on your system.

### Environment Setup

1. **Clone repository and create virtual environment**:
   ```bash
   python -m venv .venv
   ```

2. **Activate environment**:
   - Windows (PowerShell): `.venv\Scripts\Activate.ps1`
   - Linux/macOS: `source .venv/bin/activate`

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

## Reproduction & Pipeline Execution Workflow

Follow these steps to reproduce the complete dataset generation, feature engineering, model training, evaluation, and API server execution:

### Step 1: Generate Synthetic Dataset
```bash
python src/data/generate_dataset.py --patients 750 --seed 42
```
*Output*: `data/raw/synthetic_clinical_data.csv`

### Step 2: Run Data Preprocessing & Feature Engineering
```bash
python src/data/preprocessing.py
```
*Output*: `data/processed/model_dataset.csv`

### Step 3: Train Candidate Machine Learning Models
```bash
python src/models/train.py
```
*Output*: Saves trained model artifacts in `models/logistic_regression/`, `models/random_forest/`, `models/xgboost/`, and `models/best_model.joblib`.

### Step 4: Evaluate Models & Generate Metric Artifacts
```bash
python src/models/evaluate.py
```
*Output*: `experiments/results.csv`, `experiments/confusion_matrices.png`, `experiments/calibration_curves.png`

### Step 5: Generate SHAP Visualizations
```bash
python src/explainability/shap_explainer.py
```
*Output*: `experiments/shap_summary.png`

### Step 6: Start FastAPI Prediction Microservice
```bash
uvicorn src.service.app:app --reload --port 8000
```
- Interactive API Documentation (Swagger UI): `http://localhost:8000/docs`
